### 3-1. 응급도 단서 레이어 ⏱ 1.5일

환자 10명에게 **눈으로 볼 수 있는 단서** 4가지를 준다.

| 차원 | 값 |
|---|---|
| 움직임 | 보행 가능 / 목적성 있음 / 미약 / 없음 |
| 자세 | 서 있음 / 앉음 / 무릎 / 엎드림 / 누움 |
| 호흡 표시 | 보통 / 빠름 / 안 보임 |
| 반응성 | 반응함 / 지연 / 무반응 |

- [ ] `PatientUrgencyProfile.cs` — `PatientView`와 **별도 컴포넌트**로
- [ ] 4개 단서 → 우선순위 라벨(P1~P4) 규칙표 구현
- [ ] 라벨을 Inspector에서 직접 못 바꾸게 하기
- [ ] EditMode 테스트로 규칙 전부 검증

**→ 문서:** [`10-research/14-severity-cue-spec.md`](./10-research/14-severity-cue-spec.md) §3에 규칙표 전체

⚠️ **호흡수 같은 숫자는 절대 표시하지 않는다.** "보이는가 / 빠른가"까지만. 숫자를 넣는 순간 생체신호 측정 주장이 된다.

### 3-3. 추정 시뮬레이터 ⏱ 1일

시스템이 응급도를 "추정"하는 것처럼 보이게 만들되, 실제로는 정답에서 **일부러 틀리게** 만든다.

- [ ] 신뢰도 100% → 오답 0명 / 85% → 2명 / 70% → 3명
- [ ] 오답은 **인접 등급으로만** (P2↔P1). P3→P1 같은 극단은 금지
- [ ] 저추정(P1을 P2로) 오답이 **매 조건 최소 1명**
- [ ] 같은 seed면 항상 같은 결과

**→ 문서:** [`20-engineering/23-uncertainty-hud-spec.md`](./20-engineering/23-uncertainty-hud-spec.md) §1

### 3-4. 불확실성 표현 3조건 ⏱ 3일 ★ 논문의 핵심

같은 추정 결과를 **세 가지 다른 방식**으로 보여준다.

| 조건 | 보여주는 것 |
|---|---|
| A 확정 라벨 | `P1 IMMEDIATE` — 이것뿐 |
| B 신뢰도 등급 | `P1 IMMEDIATE` + 신뢰도 ●●○ + 차순위 후보 |
| C 판단 보류 | 신뢰도 낮으면 `UNCERTAIN / CHECK DIRECTLY` |

- [ ] 월드 카드 3조건 레이아웃
- [ ] HUD nearby 패널에도 반영
- [ ] **색 + 문자 이중 부호화** (색약이어도 읽히게, HoloLens 대비)
- [ ] 세 조건 카드의 **물리적 크기를 동일하게** (시야 점유가 달라지면 교란)
- [ ] 9조합(3표현 × 3신뢰도) 스크린샷 찍어두기 ← 논문 그림이 된다
