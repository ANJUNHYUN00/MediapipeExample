## A. 기존 기능 재검증 (파일럿 전 1회)

카드 위치·billboard 보정이 마지막 대화 이후 반영되었으나 **전수 Play Mode 검증이 되지 않았다.** 여기서 끝낸다.

### A1. 환자 10명 전수
각 환자에 대해:

| ID | 포인팅 인식 | 0.7초 dwell | 카드 노출 | 카드 위치(머리 위) | Checked 전환 | 비고 |
|---|---|---|---|---|---|---|
| TR-001 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-002 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-003 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-004 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-005 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-006 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-007 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-008 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-009 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |
| TR-010 | ⬜ | ⬜ | ⬜ | ⬜ | ⬜ | |

- [ ] seated / kneeling / leaning / lying 각 자세에서 카드 offset이 적절한가
- [ ] billboard가 어느 각도에서도 정면을 향하는가 (카메라 forward가 아닌 "카드→카메라" 방향 사용 확인)

### A2. 콜라이더와 raycast 경로
- [ ] 10명 전원이 `Patient` 레이어(인덱스 6)에 있는가
- [ ] 10명 전원에 선택 가능한 콜라이더가 있는가
- [ ] 레일·좌석·기둥이 환자 raycast를 가리지 않는가
- [ ] 재난 연출 오브젝트가 raycast를 가리지 않는가 (내부 잔해는 visual-only여야 함)
- [ ] 외부 대형 잔해 콜라이더가 이동 통로를 막지 않는가
- [ ] `TenPatientIdentityAndPlacementMenu` 실행 → Console 경고 0
- [ ] 환자 간 collider overlap 경고 없음

### A3. HUD
- [ ] 가까운 4명이 거리순으로 정렬되는가
- [ ] 화면 밖 환자의 좌/우 방향·거리가 올바르게 갱신되는가
- [ ] Checked 전환 시 count / nearby 색 / LOCAL TEAM SYNC가 갱신되는가
- [ ] `SIMULATION ONLY` 상시 표시
- [ ] 1920×1080 / 2560×1440에서 HUD가 잘리지 않는가
- [ ] HUD가 dwell·pointer 입력을 막지 않는가 (GraphicRaycaster 제거 상태 확인)

### A4. Pose 강건성
- [ ] 조명이 어두울 때 포인터가 유지되는가
- [ ] 사용자 키·팔 길이가 다를 때 (최소 2명으로 확인)
- [ ] 카메라 높이를 바꿨을 때
- [ ] **팔을 내렸을 때 오선택이 없는가** (`PointerRaycaster`가 즉시 클리어하는지)
- [ ] 화면 가장자리 환자를 선택할 수 있는가
- [ ] 근접 배치된 두 환자를 구분해 선택할 수 있는가
- [ ] `PARTIAL` / `LOST` 상태에서 포인터가 사라지는가

### A5. 기본
- [ ] Unity Console 에러 **0개**
- [ ] Python 콘솔 예외 없음
- [ ] 5분 연속 실행 시 프레임 드랍이나 메모리 증가 없음

## B. 신규 기능 검증 (Level 1·2 완료 후)

### B1. 단서 레이어
- [ ] 10명의 cue 조합 → 라벨이 규칙표와 일치 (EditMode 테스트 통과)
- [ ] Animator 활성화 후 환자 위치·회전·collider 불변
- [ ] 8m 거리에서 움직임 cue 구분 가능
- [ ] seated / prone / supine에서 호흡 애니메이션이 보이는가
- [ ] `Responds` 반응이 dwell 시작 시 트리거되는가
- [ ] P4 환자의 시각 표현이 잔혹하지 않은가 (스크린샷 확보)

### B2. 추정 시뮬레이션
- [ ] 동일 seed + reliability → 오라벨 배치 동일 (2회 실행 비교)
- [ ] R100에서 오라벨 0건
- [ ] R85에서 2건, R70에서 3건
- [ ] 모든 조건에서 저추정 오라벨 ≥ 1건
- [ ] P4가 오라벨 대상이 되지 않음
- [ ] 인접 등급으로만 교란 (P3→P1 없음)

### B3. 불확실성 표현 3조건
- [ ] 세 조건 카드의 물리적 크기가 동일
- [ ] 색을 제거해도 라벨 판독 가능 (색각 시뮬레이터)
- [ ] 조건 B: 신뢰도–오라벨 상관이 설계값 근처
- [ ] 조건 C: 불필요한 보류와 놓친 보류가 모두 존재
- [ ] 조건 C: 보류 시 라벨이 노출되지 않음
- [ ] **9조합(3표현 × 3신뢰도) 스크린샷 확보** ← 논문 그림 자산

### B4. 로깅
- [ ] 세션 1회 → 4개 파일 생성
- [ ] Play Mode 강제 중단 후에도 직전까지 보존
- [ ] `trials_*.csv` 행 수 == 블록 수 × 환자 수
- [ ] 모든 `dwell_start`에 짝이 있음
- [ ] 개인 식별 정보 없음
- [ ] `validate_logs.py` 통과

### B5. 조건 전환
- [ ] 3블록 연속 실행 시 표현 조건이 정확히 전환
- [ ] 마우스 조건과 제스처 조건의 raycast 파라미터 동일
- [ ] 판단 입력(1~4)이 제스처 조작과 충돌하지 않음
- [ ] SAGAT 프로브가 정상 동작하고 로그에 남음
- [ ] 시나리오 Export → Import 왕복 후 배치 동일

## C. 매 세션 전 (본 실험)

실험자가 참가자 입실 전 5분 안에 확인한다.

- [ ] Python Pose 프로세스 실행, 콘솔 에러 없음
- [ ] Unity Play Mode 진입, Console 에러 0
- [ ] HUD에 `LINK CONNECTED` / `POSE TRACKING` 표시
- [ ] 포인터 캘리브레이션(`C` 키) 수행
- [ ] `ExperimentConfig`의 `sessionId`가 이번 참가자와 일치
- [ ] `scenarioSetId` / 조건 순서가 배정표와 일치
- [ ] 로그 디렉터리에 이전 참가자 파일이 없거나 덮어쓰지 않음
- [ ] 조명 조건 기록
- [ ] 카메라 높이·참가자 키 기록
- [ ] 설문지(NASA-TLX / SUS / 신뢰) 준비
- [ ] 동의서 서명본 확보

**세션 직후**
- [ ] 로그 4개 파일 생성 확인
- [ ] `validate_logs.py` 실행
- [ ] 백업 폴더로 복사
- [ ] 특이사항 메모 (중단, 기기 문제, 참가자 반응)
