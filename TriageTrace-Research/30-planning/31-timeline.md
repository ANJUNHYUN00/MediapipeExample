## 1. 전략 요약

> **11~12월 마감은 데스크톱 버전으로 확보한다. HoloLens 2는 3월 ISMAR용이다.**

HL2 이식은 파이프라인만 4~5주다. 12월 전에 이식하려 하면 11~12월 마감 3건을 전부 놓친다. 두 갈래를 병렬로 돌린다.

```
트랙 A (주): 데스크톱 계측 → 파일럿 → 본 실험 → 3건 투고
트랙 B (병렬): 툴체인 아카이브 → HL2 파이프라인 검증 → 이식 → ISMAR
```

트랙 B는 트랙 A의 여유 시간에만 진행하되, **H-0(아카이브)와 H-1(빈 씬 배포 검증)만은 예외적으로 9~10월에 반드시 끝낸다.** 늦게 발견하면 복구가 불가능하기 때문이다.

## 3. 크리티컬 패스

```
L1-4 로깅 ──→ 파일럿 ──→ 본 실험 ──→ AH/HCIK/VR 3건
   ↑
9월 말까지 반드시
```

로깅이 밀리면 전부 밀린다. **L1-4를 가장 먼저 끝내도 된다면 그렇게 하라.** 단서 레이어(L1-1)보다 먼저 해도 무방하다 — 로깅은 기존 `StateChanged` 이벤트만으로도 착수 가능하다.

```
H-0 아카이브 ──→ H-1 실기 배포 ──→ H-2~H-10 ──→ ISMAR
   ↑                  ↑
이번 주            10월 안에
```

H-1이 10월을 넘기면 ISMAR은 포기한다. 동결된 툴체인 프로젝트는 여기서 무너지고, 12월에 발견하면 회복 불가다.

## 5. 버퍼

- 11월 실험 기간에 **1주 버퍼**가 없다. 참가자 노쇼·장비 문제를 감안해 **10월 마지막 주부터 실험을 시작**하는 것으로 잡았다
- 트랙 B에는 명시적 버퍼가 없다. **Unity 버그를 최소 1건 직접 우회한다고 가정**하고, H-2~H-3에 각각 하루씩 여유를 숨겨 두었다
