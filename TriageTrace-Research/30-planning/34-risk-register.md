## 🔴 치명

### RK-01 · HoloLens 2 하드웨어 고장
**확률** 낮음 · **영향** 트랙 B 전면 중단
생산이 2024년 12월에 종료되어 **새로 구매할 수 없다.** 실험 중 고장 시 대체 불가.
**대응**
- 모집 전 학교·연구실 예비 기기 보유 여부 확인
- 중고 시장 가격·가용성 사전 조사 (기록만 해두기)
- 실패 시: Quest 3 전환 (약 70만원, 시선 추적 없음) 또는 데스크톱 결과만으로 ISMAR 대신 CHI Poster 집중
**현 상태** ⬜ 예비 기기 확인 안 됨

### RK-02 · HL2 툴체인 다운로드 소멸
**확률** 중간 (Microsoft가 아카이브 페이지를 정리할 수 있음) · **영향** 이식 영구 불가
**대응** [`41-toolchain-archive.md`](../40-checklists/41-toolchain-archive.md) 즉시 실행. 시간당 가치가 가장 높은 완화책.
**현 상태** 🔴 **미완료 — 이번 주 최우선**

### RK-03 · 로깅 누락으로 실험 데이터 손실
**확률** 중간 · **영향** 해당 세션 전체 무효, 재모집 불가능할 수 있음
세션이 끝난 뒤에는 복구가 불가능하다.
**대응**
- 이벤트마다 flush (스펙 요구사항)
- L1-8 검증 스크립트로 **매 세션 직후** 검사
- 파일럿 전체 로그를 검증 스크립트로 통과시킨 뒤 본 실험 착수
- 세션 중 로그 파일 크기를 실험자가 눈으로 확인
**현 상태** ⬜ L1-4, L1-8 미착수

## 🟠 높음

### RK-04 · IRB 승인 지연
**확률** 중간 · **영향** 본 실험 시작 지연 → 11~12월 마감 3건 전부 상실
심의에 2~4주가 걸리고, 재난 시나리오 + 웹캠 조합은 추가 질의를 부를 수 있다.
**대응** **10월 중순 제출**을 일정에 고정. 시나리오 스크린샷을 첨부해 비잔혹성을 선제 입증. 파일럿은 승인 전에도 가능한 범위(연구자·지인 대상 기능 점검)로 분리.
**현 상태** ⬜ R-1 미착수

### RK-05 · 참가자 모집 실패
**확률** 중간 · **영향** N 부족 → 검정력 부족
24명을 3주에 처리하려면 주 8명, 주당 11시간 세션 운영.
**대응** 10월 중순부터 모집 시작. 16명을 하한으로 두고, 미달 시 within-subject 설계의 이점을 강조하며 검정력 한계를 논문에 명시. 신뢰도 요인을 between에서 within으로 바꾸는 축소안도 검토(세션이 길어지는 대신 N 요구가 줄어듦).
**현 상태** ⬜ R-3 미착수

### RK-06 · 파일럿에서 오라벨 검출률 0
**확률** 중간 · **영향** 주 종속변수 무의미 → 설계 재작업 2주
참가자가 단서를 읽지 않고 추정을 그대로 따르면 표현 조건 간 차이가 나오지 않는다.
**대응**
- 지시문에서 추정 불완전성을 **명시적으로 고지** (설계에 반영됨)
- 단서 판독성을 파일럿에서 별도 확인 (8m 거리 판독 테스트)
- 실패 시: 오라벨을 더 명백하게, 또는 단서 애니메이션 강화, 또는 오라벨 비율 상향
**현 상태** ⬜ 파일럿 미실시

### RK-07 · 데스크톱 연구의 생태학적 타당성 비판
**확률** 높음 (리뷰에서 반드시 나온다) · **영향** 국제 학회 리젝
**대응**
- Nelson et al. (arXiv 2601.08186)의 단계적 시뮬레이션 논거를 방법론적 근거로 인용
- HMD 일반화를 **주장하지 않는다**
- 2027-03 ISMAR에서 HL2 전이를 보여 이 비판을 구조적으로 해소
**현 상태** 🟡 프레이밍은 준비됨, 문헌 원문 확인 필요

### RK-08 · "Wizard-of-Oz 추정기" 비판
**확률** 높음 · **영향** 기여 약화
*"트리아지 옷을 입은 불확실성 시각화 연구"*
**대응** 제목과 초록에서 인정한다. 시뮬레이션된 정확도 수준을 실제 시스템 수치(89%, 82.8%, 10/15)로 인용해 임의값이 아님을 보인다. 실제 시스템으로는 정확도를 조작할 수 없으므로 이 설계가 오히려 우월함을 논의에서 명시.
**현 상태** 🟡 [`03`](../00-overview/03-strategic-judgment.md) §4에 방어 논리 준비됨

## 🟡 중간

### RK-09 · Unity 버전 충돌 (이미 발생)
현재 `6000.3.10f1`, HL2 상한 `6000.0.49f1`.
**대응** 프로젝트 분기 전략 채택 → [`24`](../20-engineering/24-hololens2-port-plan.md) §1. 데스크톱 프로젝트는 손대지 않는다.
**현 상태** 🟡 전략 확정, 실행 전

### RK-10 · Animator 활성화로 인한 배치 회귀
`PatientModelIntegrationMenu`가 의도적으로 Animator를 비활성화한다. 이를 뒤집으면 위치·collider가 변할 수 있다.
**대응** Root Motion off 강제. 변경 후 `TenPatientIdentityAndPlacementMenu` 검증 재실행을 수용 기준에 포함.

### RK-11 · 외부 에셋 재설치 실패
`Subway Full Package`, `Characters`, `FirstPerson` 등이 Git에 없다. HL2 분기 프로젝트에서 재설치가 필요하다.
**대응** D-2 `ASSET_SETUP.md`를 **씬 이식(H-3) 전에** 작성. 라이선스와 다운로드 경로를 지금 기록해 둘 것 (에셋 스토어에서 사라지는 경우가 있다).
**현 상태** ⬜ 미작성 — 우선순위를 올릴 것

### RK-12 · 시선 캘리브레이션 실패율
안경·콘택트·눈 수술·조명에서 실패한다. HL2 단계에서 N을 갉아먹는다.
**대응** 파일럿 5명 선행 측정. head gaze 폴백과 제외 규칙을 **사전 등록**. 캘리브레이션 상태를 참가자별로 로그에 남긴다.

### RK-13 · 한국어 TMP 폰트 글리프 누락
이미 발생했던 문제. 국내 학회 스크린샷에서 재발 가능.
**대응** 영문 HUD 유지 + 캡션 설명, 또는 필요 글리프만 포함한 Static TMP Font Asset 생성.

### RK-14 · 중복 투고 정책 위반
동일 데이터를 AH / HCI Korea / IEEE VR Poster에 투고한다.
**대응** 각 CFP의 중복 투고 조항을 **투고 전 직접 확인.** 특히 AH Short(8p)와 IEEE VR Poster(2p)의 동시 심사 중 상태. 국내↔국제는 일반적으로 허용되나 확인은 필수.
**현 상태** ⬜ 미확인

### RK-15 · Unity 버그 (수정 없음)
HL2 툴체인은 동결되어 버그 픽스가 영원히 없다. DX12 성능 저하는 이미 알려진 영구 미해결 건.
**대응** D3D11 강제(첫날). 최소 1건은 직접 우회한다고 가정하고 H-2~H-3에 여유 확보.

### RK-16 · 학회 마감일 오인
KSC / HCI Korea / 전자공학회 / KICS의 마감은 예년 패턴 추정이다. 공식 페이지 렌더링 확인에 실패했다.
**대응** [`33`](./33-venues-and-deadlines.md) §4의 4건을 이번 주에 직접 확인.
**현 상태** 🔴 미확인

### RK-17 · 세션 시간 초과
78분 설계이나 실제로는 더 걸릴 수 있다. 피로가 후반 블록을 오염시킨다.
**대응** 파일럿에서 실측. 초과 시 블록당 환자 수를 10명 → 8명으로 축소.
